# Example brand: CREATORS (creators-demo)

This directory doubles as the structural template for your own brands: create
`brands/<slug>/brand.json` with the same fields and the engine seeds the brand
on first read. Real brand directories are gitignored — only this example ships
with the repo.

CREATORS is the demo brand of this project (an AI ecosystem network from
Stuttgart). Its campaign content in `data/fixtures/demo/` is fictional demo
data; marketing copy is German because that is the brand's market language.
